  • Understand resolution, color modes, and canvas sizes
  • Save and organize your work effectively

  • Implement backup strategies to never lose work

Creating New Documents 📄

Starting with the right document settings saves hours of work later. Let's demystify all those options in the New Document dialog!

🌟 Golden Rule: It's always better to work larger and scale down than to work small and scale up. Quality only goes one direction - down!

New Document Settings

📐 Document Presets

Purpose Size (pixels) DPI Color Mode
Web/Social Media 1920×1080 or 1080×1080 72 RGB
Digital Illustration 3000×3000 minimum 300 RGB
Print (A4) 2480×3508 300 CMYK
Game Assets Power of 2 (512, 1024, 2048) 72 RGB
Concept Art 3840×2160 (4K) 72-150 RGB

🎯 Quick Setup Tips

  • Can't decide on size? Go with 3000×3000px at 300 DPI - covers most needs
  • Background: White for most work, transparent for assets/logos
  • Color mode: RGB for digital, CMYK only for professional printing
  • Bit depth: 8-bit for normal work, 16-bit for heavy editing
  • Name it well: "Project_Name_v01" not "Untitled-1"

Resolution & DPI Explained 🔍

Resolution confusion causes more headaches than any other technical aspect. Let's clear it up once and for all!

Pixels vs DPI vs PPI

graph TD A[Image Resolution] --> B[Pixel Dimensions] A --> C[DPI/PPI] B --> B1[Width × Height in pixels] B --> B2[Absolute digital size] C --> C1[Dots/Pixels Per Inch] C --> C2[Print density setting] B --> D[Digital Display] C --> E[Physical Print] D --> D1[Only pixels matter] E --> E1[Pixels + DPI = print size]

🖥️ Digital vs Print Resolution

Use Case Resolution Needed Why
Screen only 72 DPI Screens display at ~72-96 DPI
Web images 72 DPI File size matters, DPI doesn't
Professional print 300 DPI Industry standard for quality
Large posters 150 DPI Viewed from distance
Billboards 50-100 DPI Viewed from far away
💡 The Truth About DPI: DPI is ONLY relevant for printing! A 1920×1080 image is the same on screen whether it's 1 DPI or 9000 DPI. The DPI setting only tells the printer how big to print it.

Resolution Math Made Simple

📐 The Formula

Print Size (inches) = Pixel Dimensions ÷ DPI

Examples:
  • 3000×2000 pixels at 300 DPI = 10×6.67 inch print
  • 3000×2000 pixels at 150 DPI = 20×13.33 inch print
  • 3000×2000 pixels at 72 DPI = 41.67×27.78 inch... but blurry!

Color Modes & Bit Depth 🎨

Different color modes serve different purposes. Choose wrong, and your colors might look completely different than expected!

Color Mode Comparison

Mode Channels Colors Use For File Size
RGB Red, Green, Blue 16.7 million Screens, web, digital art Medium
CMYK Cyan, Magenta, Yellow, Black Fewer (subtractive) Professional printing Large
Grayscale Gray 256 shades B&W art, sketches Small
LAB Lightness, A, B All visible colors Color correction Large

Bit Depth Explained

🎯 8-bit vs 16-bit vs 32-bit

  • 8-bit: 256 levels per channel (16.7 million colors)
    • Standard for most artwork
    • Smaller file sizes
    • Fine for final art
  • 16-bit: 65,536 levels per channel (281 trillion colors!)
    • Better for heavy editing
    • Prevents banding in gradients
    • Larger files, slower performance
  • 32-bit: Floating point (infinite gradations)
    • HDR imaging
    • Professional VFX
    • Huge files!

Saving Your Work 💾

Nothing hurts more than losing hours of work to a crash. Let's build bulletproof saving habits!

Save vs Save As vs Export

💾 Understanding Save Options

  • Save (Ctrl/Cmd + S):
    • Updates existing file
    • Keeps all layers and editability
    • Use frequently while working!
  • Save As (Ctrl/Cmd + Shift + S):
    • Creates new file
    • Good for versions
    • Change name, location, or format
  • Export (Ctrl/Cmd + Shift + E):
    • For sharing/publishing
    • Flattens layers
    • Optimizes for specific use

Auto-Save & Recovery

✅ Set Up Auto-Save NOW!

  1. Edit → Preferences → File Handling
  2. Enable "Automatically Save Recovery Information"
  3. Set interval to 5-10 minutes
  4. Choose recovery folder location
  5. Enable "Create backup copy"

This WILL save your sanity one day!

File Formats Guide 📋

Each format has its superpower. Choose the right one for the job!

📁 Format Decision Tree

Format Use When Don't Use For File Size
.PSD Working files, need layers Sharing online Very Large
.PNG Web graphics, needs transparency Photos (too large) Medium-Large
.JPG Photos, web images Graphics with text/lines Small
.GIF Simple animations, tiny graphics Photos, complex art Small
.TIFF Print, archival Web (too large) Huge
.SVG Logos, icons, vectors Photos, paintings Tiny
.WEBP Modern web, best compression Compatibility needed Very Small
💡 Pro Tip: Save your working file as PSD, export a high-quality PNG for portfolio/archival, and create optimized JPGs for web sharing. Cover all bases!

Export Settings 🚀

Exporting isn't just "Save As" - it's optimizing your art for its destination!

Export for Web

🌐 Web Optimization Checklist

  • ☐ Resize to display size (no need for 4K on web!)
  • ☐ Convert to sRGB color profile
  • ☐ Strip metadata (reduces file size)
  • ☐ JPG: 80-85% quality (sweet spot)
  • ☐ PNG: Use PNG-8 if possible (smaller than PNG-24)
  • ☐ Consider WEBP for modern sites
  • ☐ Test loading speed

Naming Conventions

📝 File Naming Best Practices

  • Use descriptive names: "Forest_Landscape_v01" not "untitled_1"
  • Version control: _v01, _v02, _v03, _FINAL
  • Date format: YYYY-MM-DD for chronological sorting
  • No spaces: Use_underscores_or-dashes
  • Include purpose: _sketch, _lineart, _color, _final
  • Add specs if needed: _1080px, _300dpi, _CMYK
Good Examples:
  • ✅ Character_Design_Warrior_v03_color.psd
  • ✅ 2024-03-15_Commission_Johnson_FINAL.psd
  • ✅ Environment_Forest_Dawn_1920x1080_web.jpg
Bad Examples:
  • ❌ untitled-1 copy 2 final FINAL real final.psd
  • ❌ asdfjkl.psd
  • ❌ New Document 47.psd

Backup Strategies 🛡️

Hard drives fail. Computers crash. Files corrupt. Don't learn this lesson the hard way!

⚠️ The 3-2-1 Rule

  • 3 copies of important files
  • 2 different storage media types
  • 1 offsite backup

This is the minimum for professional work!

Backup Options

Method Pros Cons Cost
External HDD Large capacity, one-time cost Can fail, not automatic $50-150
Cloud Storage Automatic, accessible anywhere Monthly cost, needs internet $5-20/month
NAS Network access, RAID protection Complex setup, expensive $200-1000+
Version Control Track all changes, revert anytime Learning curve Free-$15/month
💔 True Story: "I lost 6 months of work when my hard drive died. Now I save to Dropbox, backup to an external drive weekly, and keep my finished pieces on Google Drive too. Never again!" - Every digital artist who learned the hard way

Common Export Scenarios 🎯

Let's walk through real-world export situations you'll face regularly!

📧 Scenario 1: Client Preview

Situation: Client wants to see work-in-progress

  1. Save your PSD (always first!)
  2. File → Export → Quick Export as JPG
  3. Resize to 1920px on longest side
  4. Quality: 80%
  5. Add watermark if needed
  6. File size should be under 2MB for email

🖼️ Scenario 2: Portfolio Upload

Situation: Uploading to ArtStation/Behance

  1. Export at highest reasonable resolution (3840px wide max)
  2. JPG format, 90-95% quality
  3. Embed sRGB color profile
  4. Include your name in filename
  5. Create both landscape (16:9) and square (1:1) crops

🖨️ Scenario 3: Print Preparation

Situation: Preparing for professional printing

  1. Confirm print size with printer
  2. Ensure 300 DPI at print size
  3. Convert to CMYK (ask printer first!)
  4. Add 0.125" bleed if needed
  5. Export as TIFF or PDF
  6. Keep RGB version for yourself

🎮 Scenario 4: Game Asset

Situation: Creating assets for game development

  1. Use power-of-2 dimensions (512, 1024, 2048)
  2. Export as PNG with transparency
  3. Create multiple resolutions (texture atlasing)
  4. Minimize file size (use PNG-8 if possible)
  5. Test in-engine regularly

Practice Exercises 📝

📐 Exercise 1: Resolution Test

Objective: Understand resolution impact

Instructions:

  1. Create three documents:
    • 500×500px at 72 DPI
    • 500×500px at 300 DPI
    • 2000×2000px at 72 DPI
  2. Draw the same simple artwork in each
  3. Export all as JPG
  4. Compare file sizes
  5. Try printing each - notice the difference?

Learn: How resolution affects file size and print quality

📁 Exercise 2: Format Comparison

Objective: Experience format differences

Instructions:

  1. Create artwork with:
    • Transparent areas
    • Gradients
    • Text
    • Photos/textures
  2. Export as: PSD, PNG, JPG (various qualities), GIF
  3. Compare:
    • File sizes
    • Quality
    • Transparency support
    • Loading speed

🗂️ Exercise 3: Organization Challenge

Objective: Build good organizational habits

The Challenge:

  1. Set up a complete folder structure for a fake project
  2. Create at least 5 "versions" with proper naming
  3. Export for 3 different purposes (web, print, social)
  4. Write a README.txt with:
    • Project description
    • Version history
    • Export specifications

💾 Exercise 4: Backup Drill

Objective: Establish backup routine

Instructions:

  1. Choose a backup solution (cloud or external)
  2. Set up automatic backup if possible
  3. Create backup of current projects
  4. Test recovery - can you restore a file?
  5. Set calendar reminder for manual backups

Success: You have at least 2 copies of all important work!
